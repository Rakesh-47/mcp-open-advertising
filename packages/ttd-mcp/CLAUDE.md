# ttd-mcp

Platform notes for this package: quirks that are easy to forget when editing it. Repo-wide conventions are in the [root CLAUDE.md](../../CLAUDE.md).

Surfaces TTD's documented Platform API only — REST (`/v3/...`) and GraphQL (`/graphql`). Per TTD Foundations §6, bulk operations (>100-record campaign/ad-group creates and updates) are only available through GraphQL. TTD's sample for creating >100 campaigns uses a separate file-based `bulkCreateCampaigns` flow, which no tool here wraps (see `graphql-reference://ttd`). TTD documents `createMutationBulk` on its GraphQL "Bulk operations" page: `mutationVariables` is an array of JSON strings, each keyed by the mutation's variable name, and per-input errors of a job arrive as `mutationGqlErrors` with the failed input's `index`; `ttd_graphql_mutation_bulk` wraps each input under the mutation's one declared variable. It has never been run against TTD and a mutation job cannot be cancelled, so it is **sandbox-only**: against production it refuses (and its dry run says so) unless the operator sets `TTD_ALLOW_UNVERIFIED_MUTATION_BULK=true`, and it takes at most 100 inputs (TTD allows 1000) until a sandbox run confirms the request (#231). Sandbox: set `TTD_USE_SANDBOX=true` to route at `ext-api.sb.thetradedesk.com` (weekly clone of prod, no real spend; audience uploads and `/v3/study` not supported).
